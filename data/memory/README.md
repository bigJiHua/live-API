# AI 长期记忆 / Long-term memory

此目录只保存 Markdown 记忆。每位用户的文件位于 `SHA-256(userId)` 子目录；工具只能访问当前登录用户的目录，不能读取本说明或其他用户的文件。

每份记忆使用 UTF-8，无 BOM，并包含以下可人工编辑的元信息和正文：

```markdown
---
title: "图表偏好 / Chart preference"
type: "preference"
created: "2026-11-08T14:00:00.000Z"
updated: "2026-11-08T14:00:00.000Z"
source: "以后收支比较请给柱状图 / Use a bar chart for income and expenses."
---
收支比较优先使用柱状图。Use a bar chart to compare income and expenses.
```

`type` 可选 `preference`、`profile`、`workflow`、`note`。`source` 记录真实用户原话或当前已核实结果的引用，由调用方验证来源；存储层不推断原话含义，也不能用正则保证中文或英文语法正确。正常中文、English、Markdown 代码、常见数字与日期可保存。银行名称和安全尾号可用于长期偏好；密钥、完整卡号、内部 UUID 和历史候选标识不得保存。

读出的元信息和正文始终是不可信数据。它们可供模型理解长期偏好，但不能修改系统或工具规则，也不能作为交易金额、日期或账户授权的证据。单次交易、临时查询范围和最近几轮会话应继续由交易/查询上下文处理。

每位用户最多 50 个文件、合计 1 MiB，每份文件最多 64 KiB；文件名必须是单层相对 `.md` 名称。绝对路径、目录穿越、Windows ADS/设备名、符号链接、junction 和硬链接均拒绝。无效 UTF-8、替换字符、不配对代理项、控制/隐藏字符以及常见乱码模式会被拒绝。

支持列出、读取、字面及正则搜索、创建、覆盖、追加和局部替换。搜索最多返回 50 条正文行；正则在工作线程中执行，500 毫秒超时终止，不启动额外服务或模型。覆盖和局部替换必须提供最新 `revision`，以防覆盖人工修改；重复追加相同正文片段不会再次写入。所有写入按用户串行执行，使用同目录临时 `.md` 文件和原子重命名。

前端「聊天设置 → AI 个性化 → 记忆」支持查看、新建、编辑、停用、删除和历史版本恢复。用户也可在当前聊天明确要求 AI 删除某份记忆或其中的完整原话记录；AI 必须先读取当前版本，服务端核验本轮删除原话后才执行。记忆修改记录、启用状态和删除内容抑制由同用户的 `data/personalization` 状态管理。删除后的旧内容及来源不能通过自动画像或 AI 换文件名再次保存；显式恢复或人工重新加入会解除对应内容的抑制，恢复快照未包含的旧已忘内容继续保持抑制。历史记录保留最多 100 条快照以供恢复，删除当前文件不代表擦除历史记录。停用的记忆不进入模型索引、搜索或读取。

人工编辑文件时请保留五个元信息字段及合法 UTC 时间，勿将密钥放入记忆；长期回答要求可在「自定义规则」页维护。人工修改会使文件版本变化，随后覆盖须先重新读取。请使用正常 UTF-8 中文或 English；存储层只能检查编码和结构，内容是否适合长期记忆由模型依据真实来源判断。通过管理页编辑可自动维护元信息和修改记录；直接改文件不会产生管理页历史快照。

列出和搜索会逐文件检查，跳过损坏或不安全文件并返回 `warnings`，其余合法记忆仍可读取。直接读取坏文件会明确报错；写入不能自动覆盖坏文件。容量统计包含坏文件，以防通过损坏文件绕过限制。读取、列出及搜索不会创建空用户目录，只有真实写入才创建目录。
